# "host"         the host and every name below it is dropped from the bad-host table.
# "host shared"  a shared-hosting, tunnel or registry domain: the name itself is dropped, but hosts
#                below it (someone's page on blogspot.com or github.io) may be listed.
# Parent names of every entry are protected too, so a lookup that walks up from one of these hosts
# can never hit. Add a host here when a user reports a false warning; never remove one to "make a
# list bigger". The build prints how many upstream entries each rule dropped.
