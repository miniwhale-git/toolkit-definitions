# Packages the app list must never contain, however the sources look. One per line ("#" starts a comment):
#   package            this exact package is never listed (Android package names are case-sensitive)
#   prefix.*           no package under this prefix is listed
#   package listed     an exception under a protected prefix: a stalkerware name that imitates a system
#                      one. It stays listed, labelled "... (name used by stalkerware)", because the app
#                      tells a real system app from an imitation by its signer.
#   package known      a source is known to list it; dropping it is expected and not counted as new.
# The build drops every upstream entry that hits this list and prints each one. More than 3 new hits
# in one run stop the build: that looks like a tampered source. Add a package when a user reports a
# false warning; never remove one to "make a list bigger".
#
# Not on this list on purpose: apps the sources list as monitoring apps (Microsoft Family Safety,
# Family Link and the like). Those are real findings, shown with the softer "watchware" label.
