# Packages the app list must never contain, however the sources look. One per line ("#" starts a comment):
#   package            this exact package is never listed (Android package names are case-sensitive)
#   prefix.*           a system prefix. A package under it that no exact line names is not dropped: it is
#                      listed as "... (name used by stalkerware)" (or watchware, spyware) and printed,
#                      because stalkerware hides behind system-like names and the app tells a real system
#                      app from an imitation by its signer. It never counts toward the failure gate.
#   package listed     the same, already reviewed (from the sources on 2026-11-12).
#   package known      a source is known to list it; dropping it is expected and not counted as new.
# The build drops every upstream entry that hits an exact line (or keep-certs.txt) and prints each one.
# More than 3 new hits of those in one run stop the build: that looks like a tampered source. Add a
# package when a user reports a false warning; never remove one to "make a list bigger".
#
